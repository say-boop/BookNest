# 📚 BookNest

REST API для ведения личного списка книг. Позволяет регистрироваться, добавлять книги, отслеживать статус чтения, ставить оценки, а также искать и фильтровать свою библиотеку.

## ✨ Возможности

- **Аутентификация**: JWT-токены, регистрация и вход по email. Хэширование паролей (Argon2).
- **Личный кабинет**: получение профиля текущего пользователя.
- **Изоляция данных**: Каждый пользователь видит и редактирует только свои книги.
- **Управление книгами**: CRUD операции, статусы (`want_to_read`, `reading`, `read`), оценки (1-10), заметки, дата прочтения.
- **Фильтрация и поиск**: По статусу, по названию/автору, с пагинацией.
- **Сортировка**: По дате добавления и по рейтингу.
- **Статистика**: Количество книг по каждому статусу.
- **Кеширование**: Эндпоинт статистики (`/books/stats`) кешируется в Redis (TTL 120 секунд). Кеш автоматически инвалидируется при добавлении, изменении или удалении книг.

## 🛠 Стек

- **Python** 3.12
- **FastAPI**
- **PostgreSQL 17** — база данных
- **SQLAlchemy 2.0** (async) + **psycopg** — ORM и драйвер
- **Alembic** (миграции)
- **Pydantic v2**
- **Poetry** (управление зависимостями)
- **Docker & Docker Compose** — контейнеризация
- **Pytest** + **pytest-asyncio** + **httpx** — тестирование
- **Redis 7** — кеширование (клиент `redis.asyncio`)

## 🚀 Быстрый старт

Самый простой способ запустить проект — использовать Docker.

### 1. Клонировать репозиторий

```bash
git clone https://github.com/say-boop/BookNest.git
cd BookNest
```

### 2. Настроить переменные окружения

Создай файл .env в корне проекта (на основе .env.example) и заполни его:

```env
POSTGRES_USER=name_user
POSTGRES_PASSWORD=your_secure_password
POSTGRES_DB=name_db
POSTGRES_PORT=5432
SECRET_KEY=your_super_secret_jwt_key
ALGORITHM=HS256
```

(Секретный ключ можно сгенерировать командой `python -c "import secrets; print(secrets.token_urlsafe(32))"`).

### 3. Запустить приложение

```bash
docker-compose up --build
```

(При первом запуске Docker скачает образы, соберет приложение, автоматически применит миграции базы данных и поднимет Redis).

### 4. Открыть документацию

Перейти по адресу: [клик](http://localhost:8000/docs)


## 📡 API Endpoints

## Пользователи

| Метод  | Путь                         | Описание |
|--------|------------------------------|----------|
| POST   | `/users`                     | Регистрация нового пользователя |
| POST   | `/users/login`               | Вход в систему (получение JWT) |
| GET    | `/users/me`                  | Получить данные своего профиля |

## Книги (Все требуют JWT-токен)

| Метод  | Путь                         | Описание |
|--------|------------------------------|----------|
| GET    | `/books`                     | Список книг (с фильтрацией, поиском, сортировкой) |
| POST   | `/books`                     | Создать книгу |
| GET    | `/books/{book_id}`           | Получить книгу по ID |
| PATCH  | `/books/{book_id}`           | Обновить книгу |
| DELETE | `/books/{book_id}`           | Удалить книгу |
| PATCH  | `/books/{book_id}/rating`    | Поставить оценку (1-10) |
| GET    | `/books/stats`               | Статистика по статусам |


## Параметры `GET /books`

| Параметрд      | Тип      | Допустимые значения               | Описание |
|----------------|----------|-----------------------------------|----------|
| `status`       | string   | `want_to_read`, `reading`, `read` | Фильтр по статусу |
| `search`       | string   | любая строка                      | Поиск по названию и автору |
| `sort`         | string   | `created_at`, `rating`            | Поле для сортировки |
| `order`        | string   | `asc`, `desc`                     | Направление сортировки |
| `limit/offset` | integer  | любые числа                       | Пагинация |


## 🧪 Тестирование

Проект покрыт **39 тестами API** (100% успешных), которые проверяют:
- Авторизацию и JWT-токены (включая истекшие и невалидные токены).
- CRUD-операции с книгами.
- Изоляцию данных (пользователь не может получить/изменить/удалить чужую книгу).
- Фильтрацию, поиск, сортировку и пагинацию.
- Статистику (только по книгам текущего пользователя).

Тесты используют отдельную тестовую базу данных (`booknest_test_db`), которая создается автоматически, а изоляция между тестами обеспечена через откат транзакций (`rollback`).

### Запуск тестов

Перед запуском убедись, что база данных в Docker запущена (`docker-compose up -d`), так как тесты подключаются к ней локально (через `127.0.0.1:5432`).

```bash
poetry run pytest -v
```
